## SpringBoot.

- Es una herramienta (framework) que simplifica la creacion de proyectos Web
 - Tu app ya incluye el servidor web
 - Si agregas una base de datos Springboot lo reconoce y lo configura por ti
 - Estructura de proyectos, Application.java, Base de datos, Endpoints
 - Compatibilidad con Spring tradicional

## Maven
Maven es una herramienta de gestión y construcción de proyectos (build tool), principalmente usada en el ecosistema Java. Fue creada por Apache y se ha convertido en un estándar para proyectos Java desde hace muchos años.

### ¿Para qué sirve?

1. Gestión de dependencias: descarga automáticamente las librerías que tu proyecto necesita (y las dependencias de esas librerías) desde repositorios centrales, sin que tengas que descargarlas manualmente.

2. Estandarización de estructura: define una estructura de carpetas estándar (src/main/java, src/test/java, src/main/resources, etc.) que hace que cualquier desarrollador entienda rápido cómo está organizado el proyecto.

3. Automatización del ciclo de vida del proyecto: compilar, testear, empaquetar, instalar y desplegar código, todo con comandos simples.

4. Configuración centralizada: todo se define en un archivo ```pom.xml``` (Project Object Model), donde declaras dependencias, plugins, versiones, etc.

### Comandos principales

| Comando | Qué hace |
|---|---|
| `mvn clean` | Elimina la carpeta `target/` (archivos compilados anteriores). |
| `mvn compile` | Compila el código fuente del proyecto. |
| `mvn test` | Ejecuta las pruebas unitarias. |
| `mvn package` | Compila y empaqueta el proyecto en un `.jar` o `.war`. |
| `mvn install` | Instala el paquete en el repositorio local (`~/.m2`), disponible para otros proyectos locales. |
| `mvn deploy` | Sube el paquete a un repositorio remoto para compartirlo con otros. |
| `mvn validate` | Verifica que el proyecto esté correcto y que toda la información necesaria esté disponible. |
| `mvn clean install` | Combinación muy usada: limpia el proyecto y luego lo instala desde cero. |
